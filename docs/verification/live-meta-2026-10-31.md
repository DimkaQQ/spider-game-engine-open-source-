# Live checks against api.meta.ai (2026-10-31)

These were run from a browser page and from curl, with no mocks. Nothing here is a benchmark.

| Tool | What was run | Result |
|---|---|---|
| Model list | `GET /v1/models` | 200. Lists `muse-spark-1.3`, `muse-image-1.0`, `sam-3.1`, `muse-wonder-1.0`, `muse-voice-transcribe-1.0`, `muse-spark-1.2`, `muse-spark-1.1` |
| CORS | `OPTIONS /v1/responses` with an `Origin` header | `Access-Control-Allow-Origin: *`, methods `GET,POST,DELETE,OPTIONS`, headers `*` |
| Muse Spark 1.3 | The mobile app's agent loop with the prompt "Make a simple coin collecting game: a ball I move around, 10 coins, a 30 second timer, and a game over screen with restart" | 3 API calls (all 200), 51 s, one `render_jsx` that compiled and mounted. Screenshot: [muse-spark-built-coin-rush.png](muse-spark-built-coin-rush.png) |
| Muse Image | `POST /v1/responses`, `model: muse-image-1.0`, tool `image_generation` | 200. The reply holds an `image_generation_call` with a base64 **WebP** (not PNG) |
| SAM 3.1 | Same endpoint, `model: sam-3.1`, the generated tree and the phrase "tree" | 200. Text with `<\|box;…\|><\|mask;…\|>` tokens, decoded with `@meta-sam/parser` into a 710x839 mask (56% of the box). Result: [sam-cutout-tree.png](sam-cutout-tree.png). The raw reply is the test fixture `tests/fixtures/sam-real-response.json` |
| Muse Wonder | `POST /v1/chat/completions`, `model: muse-wonder-1.0` | 200. The old id `muse-wonder` returns `model_not_found`. With `max_tokens: 80` the whole budget was spent on reasoning and `content` was `null`, so the app asks for 6000 |
| Muse Voice (HTTP) | `POST /v1/asr/transcribe`, multipart parts `request` (JSON with `model` and `audioEncoding: "WAV"`) and `audio` | 200 with `transcript`, `audioDurationMs`, `turns`. We only had a test tone, so the transcript was empty |
| Muse Voice (realtime) | `wss://api.meta.ai/v1/asr/realtime` | **Not working from our test network** (the upgrade was refused). Untested. The app falls back to the HTTP route |
| Baseten | `GET https://inference.baseten.co/v1/models` | 401 without a key (reachable). **Not tested with a key** |

Speech recognition accuracy and real phone frame rates were not measured.
